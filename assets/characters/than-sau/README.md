# Thần Sầu

- Character ID: `than-sau`
- Tên hiển thị: `Thần Sầu`
- Tên nhập thủ công dự kiến: `Shen`, `Sầu`, `Trần Đạt Thọ`, `Thần Sầu`, `神愁`
- Tài nguyên hiện có: một sprite sheet PNG duy nhất.
- File chuẩn: `than-sau-spritesheet.png`
- Đường dẫn: `assets/characters/than-sau/than-sau-spritesheet.png`
- Bố cục dự kiến: 5 cột × 2 hàng, tổng cộng 10 frame.
- Thứ tự frame: trái sang phải, hàng trên trước, sau đó hàng dưới.

## Khi bổ sung frame riêng

Nếu sau này tách frame thành các PNG độc lập, đặt trong thư mục `frames/` theo tên:
`than-sau-00.png`, `than-sau-01.png`, ... `than-sau-09.png`.

Hiện repository chỉ có sprite sheet; chưa có các PNG frame riêng và nhân vật chưa được tích hợp vào gameplay.
